# Публикация Mini App на smilekit.vercel.app

Лендинг остаётся на Vercel, само приложение работает в процессе бота на
Railway. Vercel только проксирует путь `/app` — файлы приложения нигде не
дублируются, и для браузера всё остаётся одним источником, поэтому подпись
`initData` и куки не ломаются.

```
smilekit.vercel.app/          → лендинг (статика на Vercel)
smilekit.vercel.app/app       → Mini App    ─┐
smilekit.vercel.app/app/api/* → API курса    ├─ прокси на Railway
smilekit.vercel.app/app/media/* → фото       ─┘
```

## Шаги

**1. Публичный домен у бота на Railway.** В сервисе бота открой Settings →
Networking → Generate Domain (порт 8080, его же слушает `/internal/*`).
Получится адрес вида `smilekit-bot-production.up.railway.app`.

**2. Подставь этот адрес в [vercel.json](vercel.json)** вместо
`REPLACE-WITH-RAILWAY-HOST` — в обеих строках, без `https://` и без слэша на
конце.

**3. Переменная у бота на Railway:**

```
MINIAPP_URL=https://smilekit.vercel.app/app
```

Именно адрес Vercel, а не Railway: по этой ссылке Telegram открывает Web App,
и клиент должен видеть домен бренда. Без переменной приложение и напоминания
по курсу выключены, бот работает как раньше.

**4. Раскатай обе части:**

```bash
vercel --prod
```

Railway передеплоит бота сам после пуша в подключённую ветку.

**5. Проверь:**

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://smilekit.vercel.app/app
```

Ожидается `200`. Открой в Telegram кнопку меню «Программа» или отправь боту
`/app`.

## Почему не выложить приложение на Vercel целиком

`/app/api/*` — это состояние курса, отметки дней, ИИ-чат и загрузка фото. Всё
это живёт в том же Python-процессе, что и продающий бот, и пишет в ту же
SQLite-базу на persistent volume Railway. Статический хостинг такие ручки
отдать не может, а разносить фронтенд и API по разным доменам — значит
получить сторонний origin со всеми вытекающими.

## Ограничения прокси

- Фото уходят через Vercel: приложение ужимает снимок до 1200 px по длинной
  стороне (~200–400 КБ), так что в лимиты прокси это укладывается с запасом.
- Домен приложения нужно менять в двух местах сразу — `vercel.json` и
  `MINIAPP_URL`. Расхождение выглядит как «приложение не открывается».
