# Smilekit Telegram AI manager

Telegram-менеджер Smilekit Кыргызстан на OpenAI Responses API.

## Что умеет

- отвечает на русском, кыргызском или языке клиента;
- использует только заполненную базу знаний;
- перед отправкой проверяет каждый ответ отдельным гипервизором;
- хранит историю, краткую память клиента и начатый заказ в SQLite;
- защищён от повторной обработки Telegram-сообщений и частого спама;
- анализирует присланные фотографии без медицинской диагностики;
- распознаёт голосовые сообщения и отвечает на их содержание;
- иногда делит ответ на 2–3 естественных сообщения с индикатором набора;
- отправляет фотографии результатов по запросу клиента;
- поддерживает `/start` и `/reset`.

## Настройка

1. Заполните `knowledge_base.md` подтверждёнными данными.
2. Скопируйте `.env.example` в `.env` и задайте ключи.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Запустите: `python -m smilekit_bot`.

Для Railway задайте `DATABASE_PATH=/data/smilekit.db` и подключите persistent
volume к `/data`, иначе база будет сбрасываться при новом развёртывании.

Секреты нельзя коммитить. Если ключ когда-либо был опубликован в переписке,
репозитории или логе, его следует перевыпустить.
